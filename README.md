# PhyloClear（系统发育树查看与编辑器）

PhyloClear 是一款**中英双语**的 Windows 桌面端系统发育树查看与编辑软件，使用 **Python + Qt（PySide6）** 从零重新实现，功能对标 FigTree。

PhyloClear is a **bilingual (English/中文)** Windows desktop phylogenetic tree viewer and editor, reimplemented from scratch in **Python + Qt (PySide6)**, matching the core functionality of FigTree.

> **2.0 起正式更名为 PhyloClear**（此前为 PhyloView）。名字取自 **Phy**logenetic tree **C**ustomization, **L**ayout, **E**diting, **A**nnotation & **R**endering 的首字母；内部 Python 包名仍为 `phyloview`（仅为兼容既有源码与测试，不影响对外名称）。
>
> **0.01 起版本号重置**：本次起版本号为 **0.01**，此后每次迭代递增 **0.01**（0.01 → 0.02 → 0.03 …）。文件夹名、窗口标题、帮助-关于、exe 文件名四处始终一致。

## 功能特性 / Features

- **拖拽打开 / Drag & drop**：直接把 Newick、Nexus（`.nwk` `.tre` `.newick` `.nex` `.nexus` `.nxs` `.phy`）文件拖进窗口即可打开，也支持"文件 → 打开"。
- **加载与解析 / Loading & parsing**：内置 Newick 与 Nexus 解析器，支持引号标签、注释、枝长、支持值、`TRANSLATE` 映射、多棵树。
- **交互显示 / Interactive display**：滚轮缩放、**自由拖拽平移**（可向任意方向无限拖动，不受画布边界限制）、点击选择分支/节点。
- **多种布局 / Layouts**：矩形（枝长）、分支图（cladogram）、放射状（圆形）。
- **选择与置根 / Selection & rooting**：点击分支/节点选中，再点「置根」即以该支系为根（另可中点置根）。
- **显示开关 / Display toggles**：「节点标记 / 支持率 / 标签注释」三个分组的标题行自带勾选框，取消勾选即关闭该显示项（并禁用组内控件）。**2.1 起「标签」与「标签注释」已合并为一栏**，标签字号与显示开关都放在「标签注释」里。
- **分支排序 / Branch ordering**：按支系大小（末端类群数）升序或降序排列各支系，也可还原文件原始顺序。
- **根枝长 / Root length**：可调节根左侧根枝的长度（单位与枝长一致），随比例尺同步缩放。
- **翻转 / Flip**（0.01 起由「旋转」改名）：选中节点后点「翻转」反转其下各子支系的上下顺序，拓扑与枝长完全不变。**「翻转 / 置根 / 中点置根」排成一行，与下一行「折叠 / 展开 / 全部展开」三列对齐**；英文「置根」直接译为 **Root**。
- **折叠 / 展开 / Collapse & expand**：选中支系后点「折叠」，该支系被一个**三角形（wedge）**代替；三角形**高度可调**（单位＝叶尖间距，0 = 自动沿用被替代末端的跨度），**标签可编辑**；「展开」还原该支系，「全部展开」还原所有折叠支系。折叠后点击三角形仍可选中该支系（可用于再次展开或置根）。
- **标签注释 / Label annotations**：导入 Excel / WPS 表格（`.xlsx` `.xlsm` `.csv` `.tsv`），用 **A 列**匹配树文件里的标签，把树上显示的标签换成表格中任意几列的数据；表格单元格的**加粗 / 斜体 / 颜色**（含单元格内部分文字的富文本）也会同步到树上，而**字号始终由本软件控制**（见下方 v1.5 / v1.6 / v1.7 更新）。**多列之间的分隔符自 1.8 起默认一个空格**，可在面板自定义。
- **多种支持率指标 / Multiple support metrics**：直接打开 **QuartetScores** 输出（`100:0.106124[qp-ic:…;lq-ic:…;eqp-ic:…]`）与 **IQ-TREE** 输出（`100/100`）；右侧「支持率」组会列出该文件实际包含的全部指标，可**任选一个或多个**显示（多选数值用 `/` 连接，还可勾选「显示指标名称」加前缀）。普通树行为不变（见下方 v1.8 更新）。**自 1.9 起支持率默认为黑色，并放在分叉点左侧、入枝水平线的上方**（红框位置）。
- **样式调整 / Styling**：分支颜色、线宽、节点形状/大小/颜色、叶标签字号、显示/隐藏枝长与支持值、**枝长比例尺**；所有改动**实时生效**。**比例尺长度可输入数字；位置只需在树上直接拖动整条比例尺**（2.1 起不再需要水平/垂直偏移输入与复位按钮），拖动结果在换树、改样式、导出与保存设置时都会保留。
- **滑条 + 数值框 / Sliders**（0.01 精简）：**只有「横向拉伸」「纵向拉伸」配滑条**，滑条右侧保留可键入精确数值的输入框，两者实时双向联动；其余数值控件（根枝长、折叠高度、线宽、比例尺长度、各类字号、节点大小、小数位等）都是普通数值框。滚轮在滑条/输入框上只滚动面板，不会误改数值。
- **保存设置 = 每棵树的工程文件 / Per-tree settings files**（0.01 重新定义）：**可视化树文件 1 时**用「文件 → 保存设置...」把**该树 + 全部设置**写成一个 `*.phcproj` 文件；下回直接打开这个文件（文件 → 打开 / 加载设置 / 拖进窗口 / 命令行参数）即可**继续对树文件 1 修改编辑**。**树文件 2 另存为另一个文件**，两份设置互不干扰。文件内含树文件的绝对路径**与相对路径**（一起移动也能找到）、整套样式（布局、拉伸、颜色、字号、支持率指标、比例尺长度与拖动偏移）、界面语言、标签注释配置、窗口几何。**关闭窗口时只回写当前打开的工程文件**（且仅在树未切换时），不再有全局自动快照串场。
- **简约图标 / Icon**：0.01 新增深青色圆角方块 + 白色三分支矩形支序图图标，运用于所有窗口标题栏、「帮助 → 关于」和 exe 文件图标（`assets/PhyloClear.ico` / `.png`，运行时由 `phyloview/app_icon.py` 绘制，无需额外资源打包）。
- **颜色对话框本地化**：中文界面下点「分支颜色」弹出的取色窗口标题、按钮、标签全部为中文（强制使用 Qt 非原生对话框并逐项翻译）；切回 English 恢复英文。
- **导出 / Export**：PNG、JPEG、SVG、PDF（矢量）、Newick（编辑后写回）、**标签**（txt / csv / xlsx，格式在保存对话框里手动选择，1.9）。**PNG / JPEG 默认按 300 dpi 导出**（宽度与高度同为 300 dpi，并写入文件 DPI 元数据；PDF 亦为 300 dpi）。导出 Newick 时会带上标签表格替换后的新标签；导出标签的 csv / xlsx 可直接作为「标签注释」表格重新导入。
- **双语 / Bilingual**：顶栏语言工具条直接点击「中文 / English」即可一键切换，空画布的拖拽提示也随语言切换（2.0）。
- **稳定的视图 / Stable viewport**：调节横向/纵向拉伸、折叠高度、字号等样式时，树图**保持原来的位置与缩放**，不再跳回左上角（2.0）。
- **点击数字 / Clicking numbers**：左键单击支持率或逐枝长数字会选中对应分支，数字本身保持显示（2.0）。
- **多窗口 / Multiple windows**：已经打开一棵树后再拖入另一个树文件，会**新开一个独立窗口**加载新树，原窗口的树保持不变；拖入表格文件仍作用于当前窗口（2.0）。

> **v2.0 更新 · 更名 PhyloClear**（位于 `PhyloClear_2.0/`，旧版 `PhyloView_1.9/` 等原样保留）：

> **v1.8 更新**（位于 `PhyloView_1.8/`，旧版 `PhyloView_1.7/` 等原样保留）：

> - **数值精度**：小数位默认 6 位并在格式化后去掉尾随零，`0.761628` 完整显示而 `100` 仍是 `100`（不会写成 `100.000000`）；小数位仍可在 0–8 之间调整。

> - **标签注释分隔符默认改为一个空格**（原为 ` | `）；空格在输入框里看不见，故分组内新增「当前分隔符：' '」提示行，显示实际值的 `repr`。

> **v1.7 更新**（位于 `PhyloView_1.7/`，旧版 `PhyloView_1.6/` 等原样保留）：
> - **修正首行数据被吞掉**：此前如果导入表格时打开的是另一棵树（或还没打开树），「首行为表头」会按当时的末端名一次性判定并锁死；之后换到目标树时，第一行真实数据（如 `Amanita`）仍被当作列名，匹配数少一个。现在自动判定会**在每次换树时重新进行**，自动同步保存 / 手动刷新 / 切换工作表也都不会把它锁死；只有**手动点击**「首行为表头」才固定该选项。判定键值同时支持精确、忽略大小写、忽略空格/下划线三级回退。
> - **修正主题色被解析成白色**：Excel / WPS 的默认字体色写作 `<color theme="1"/>`，按 OOXML 主题索引这是 **dk1（Text 1，黑色）**，而 1.6 误按 `clrScheme` 的书写顺序当成了 lt1（白色），于是斜体标签在白色画布上变成白字。已修正为 `0=lt1, 1=dk1, 2=lt2, 3=dk2`；无 tint 的「自动色」不再覆盖软件自身的标签颜色，只有用户真正挑过的颜色（含带 tint 的变体、显式 RGB）才生效。
> - **未匹配提示**：匹配数小于末端数时，状态行会追加「N 个未匹配 — 检查 A 列或『首行为表头』」，便于第一时间发现丢行或拼写不一致。
> - 新增回归夹具 `samples/theme_format_sample.xlsx`（真实 WPS 主题色工作簿）与 `tests/test_gui_1_7.py`。
>
> **v1.5 更新**（位于 `PhyloView_1.5/`，旧版 `PhyloView_1.4/` 等原样保留）：
> - **导入表格做标签注释**：右侧新增「标签注释」组。**第一列（A 列）必须与树文件中的标签一致**作为匹配键，其余每列都是一个可选的候选标签；勾选想显示的列，多列之间用可自定义的「分隔符」连接后替换末端标签。**没有匹配到行的末端保持原标签不变**。
> - **三种导入方式**：组内「导入表格...」按钮、菜单「文件 → 导入标签注释...」，或**直接把表格文件拖到软件窗口里**。（拖进来的树文件照旧打开树，表格文件则用于替换标签。）
> - **改表格即改树上标签**：默认勾选「自动同步」，表格在 Excel / WPS 里改完保存后，树上的标签会**自动刷新**（同时用文件系统监听 + 定时轮询，兼容"先写临时文件再替换"的保存方式）；也可随时点「刷新表格」手动重载，或点「清除表格」恢复原始标签。
> - **多工作表 / 表头**：有多个工作表时可用「工作表」下拉切换；「首行为表头」默认自动判定——若第一列第一行的值已经等于某个标签名，就判定**没有**表头行（手工表常见），否则视为列名；判定不准时可手动勾选/取消。
>
> **v1.6 更新**（位于 `PhyloView_1.6/`）：
> - **同步表格格式**：树上的标签现在会带上表格单元格的**加粗 / 斜体 / 颜色**，包括 Excel 里“一段文字中只有一部分斜体”的富文本（如属名正体 + 种加词斜体）。单元格整体格式从 `styles.xml` 读取（含主题色 theme 与色调 tint 的换算），局部格式从 rich-text 文本块读取（共享字符串与内联字符串两条路径都支持）。
> - **字号仍然归软件管**：表格里的字号（`<sz>`）一律忽略，标签大小永远取右侧「标签 → 字号」，同一份表格因此能适配不同尺寸的图。
> - **开关**：「标签注释」组新增「同步表格格式」勾选框（默认开启）；取消勾选后立即回到只用本软件字形设置的状态，标签文本一字不变。
> - **叠加规则**：加粗/斜体取“表格或本软件”的并集；颜色以表格为准，表格没给颜色时才用本软件的颜色。

> - **无需安装 Excel，也不依赖第三方库**：`.xlsx` 用标准库（zip + XML）直接解析，支持共享字符串、内联字符串、数值与多个工作表；`.csv` / `.tsv` 自动判断分隔符与编码（UTF-8/BOM、GBK）。旧的二进制格式（`.xls`、WPS `.et`）不支持，会提示另存为 `.xlsx`。
> - **导出 Newick 带上新标签**："导出为 Newick"写出的就是屏幕上显示的标签。
> - 样例：`samples/labels_sample.xlsx`（两个工作表 + 中文名/凭证号/寄主列）可直接对 `samples/dichotomous_example.nwk` 做替换演示。

> **v1.4 更新**（位于 `PhyloView_1.4/`，旧版 `PhyloView_1.3/` 等原样保留）：
> - **导出默认 300 dpi**：PNG / JPEG 的宽度与高度均按 **300 dpi** 取样（场景按 96 dpi 屏幕逻辑像素布局，故缩放系数 = 300/96 ≈ 3.125），并把 300 dpi 写入图片元数据；PDF 同为 300 dpi。（显式指定像素宽度时，元数据按实际分辨率如实写入。）
> - **新增旋转 Rotation**：右侧「布局」组「旋转」按钮 = flip individual nodes or entire subtrees —— 反转选中节点直接子节点的顺序，**不改变拓扑、支系成员与任何枝长**。
> - **新增折叠 / 展开 Collapse / expand**：右侧「布局」组的「折叠 / 展开 / 全部展开」把选中支系画成**三角形**；三角形**高度**以「折叠高度」调节（单位＝相邻末端的间距，0 = 自动，即沿用该支系所替代末端的跨度），**标签**用「折叠标签」输入框编辑（默认为该节点的名称）。三角形可被点选并映射回原支系。
> - 折叠后比例尺与不同布局（矩形 / 分支图 / 放射状）均已验证不产生重叠（布局包围盒会把三角形向下/向右超出的部分计入）。
> - 放射状布局下折叠支系不再画三角形，而是作为一根到达外圈的末端枝（附标签）显示。

> **v0.4 更新**（位于 `PhyloView_v3/`，旧版 `PhyloClear/`、`PhyloView_v2/` 原样保留）：
> - **修复鼠标移动/缩放时报错闪退**：`NodeMarkerItem` 的字符串属性 `self.shape` 覆盖了 Qt 图形项内建的 `shape()` 方法（用于碰撞检测），鼠标悬停或滚轮缩放时触发 `TypeError: 'str' object is not callable` 导致崩溃；已重命名为 `self.marker_shape`。

> - **默认样式对齐 FigTree**：默认布局改为**矩形枝长图（rectangular phylogram，枝长体现在水平段长度）**；分支为黑色细线；叶标签为黑色小字；**底部居中的枝长比例尺**；默认**不显示**节点圆圈、支持值、逐枝长数字（均可在右侧面板随时开启）。

## 运行 / Running

### 方式一：一键运行（Windows）

双击 `run.bat`，脚本会自动创建虚拟环境并安装依赖，然后启动程序。

### 方式二：手动运行

```bash
# 1. 创建虚拟环境
python -m venv .venv

# 2. 激活（Windows）
.venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行
python main.py
```

也可以直接打开一个树文件：

```bash
python main.py samples/primates.nwk
```

> 依赖：Python 3.9+（建议 3.10+），`PySide6`。

## 打包为独立可执行文件 / Packaging

已生成免 Python 环境的独立可执行文件：**`PhyloClear_0.01.exe`**（单文件，约 46 MB，文件名含版本号，已内嵌简约图标），可直接双击运行。

如需重新打包：

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name PhyloClear_0.01 --distpath . \
  --icon assets/PhyloClear.ico main.py \
  --exclude-module PySide6.QtWebEngineCore --exclude-module PySide6.QtWebEngineWidgets \
  --exclude-module PySide6.QtWebEngineQuick --exclude-module PySide6.QtQml
# 应用未用 WebEngine，排除这些模块可显著减小体积；--icon 写入 Windows exe 图标
```

> 本版本目录内**没有** `.venv`（避免再占用约 700 MB）；构建与全量测试复用工作区现存的 `PhyloView_1.9/.venv`（PySide6 6.12 + PyInstaller 6.22）。如需在本版本目录内独立重建，联网安装即可（批量 pip 安装需 WorkBuddy 沙箱越权）。

其中 `<版本号>` 为当前版本号（如 0.01），由 `--name PhyloClear_0.01` 与 `--distpath .` 将 exe 直接输出到项目根目录（文件名含版本号）。
